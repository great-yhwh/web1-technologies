<h1>Верстка 3: Семантика</h1>

<p>Макет https://www.figma.com/file/kGoIhmMmoScrC3zWEhH4fy/WEB%D0%B8C-mobile?type=design&node-id=0%3A1&mode=design&t=0Wvd14KEcic9jlv8-1</p>

<p>Фото с блоками https://disk.yandex.ru/i/uLl_eEQO77ao0g</p>

<p>Задание выполняем в ветке lesson3</p>

<p>Домашнее задание посвящается разбиению сайта на блоки, используя семантические теги (&lt;header&gt; &lt;footer&gt; &lt;nav&gt; &lt;section&gt; &lt;article&gt; &lt;aside&gt; и т.д.)</p>

<p>На фото разными цветами выделены блоки, на которые требуется разбить страницу. Верстать по макету не нужно, просто добавить элементы div c class или семантические теги, которые выделены на изображении.</p>

<p>Всем блокам задать логичное название класса. Запрещается использовать перечисление (block1, block2, block3...block378).</p>

<p>Добавить во все блоки заголовки, параграфы, списки, формы, изображения</p>

<p>Основные блоки разделить линиями (&lt;hr&gt;)</p>
