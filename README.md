<p>Установить http-server глобально <a href="https://www.npmjs.com/package/http-server">https://www.npmjs.com/package/http-server</a></p>

<ol>
    <li>Забрать изменения из репозитория <a href="https://github.com/tgulegacy/web-technologies-2024">https://github.com/tgulegacy/web-technologies-2024</a> ветка lesson2</li>
    
<li>Все изменения делаем в ветке lesson2</li>
  
  <li>Подключить другие начертания шрифта (Italic и т.д.) в файле assets/style/fonts.css по примеру из style.css</li>
  
  <li>Подключить файл assets/style/fonts.css в style.css</li>
  
  <li>Продолжить работу со страницами из 1 практики:
      <ul>
          <li>
              Для всех параграфов присвоить класс и задать стили<br>
              font-size: 16px;<br>
              line-height: 26px;<br>
              color: #1F3F68.
          </li>

  <li>
      Для заголовка h1 создать класс и присвоить стили:<br>
      font-size: 64px;<br>
      color: #1F3F68.
  </li>

  <li>
      Для заголовка h2 (на странице контакты) создать класс и присвоить стили:<br>
      font-weight: 500;<br>
      font-size: 44px;<br>
      text-align: center.
  </li>

  <li>
      Заголовку h3 создать класс и задать стили:<br>
      font-size: 36px;<br>
      text-align: center.
  </li>

  <li>
      Заголовкам h4 создать класс и задать стили<br>
      font-size: 20px;<br>
      line-height: 30px;<br>
      color: #1F3F68.
  </li>

  <li>
      Для всех полей ввода (input, textarea) задать общий класс и к нему стили:<br>
      border: 1px solid #356EAD;<br>
      box-sizing: border-box;<br>
      border-radius: 10px;<br>
      opacity: 0.4.
  </li>

  <li>
      Кнопке отправки формы присвоить класс и к нему стиль:<br>
      background: #5A98D0;<br>
      box-shadow: 5px 20px 50px rgba(16, 112, 177, 0.2);<br>
      border-radius: 10px;<br>
      font-weight: 500.<br>
      font-size: 16px;<br>
      line-height: 26px;<br>
      text-align: center;<br>
      color: #FFFFFF;<br>
      text-transform: uppercase.
  </li>

  <li>Для формы на страницы "Контакты" добавить изображение на задний фон (изображение подберите на свой вкус)</li>

  <li>
      Для кнопки Submit воссоздать стиль как на этой картинке <a href="https://www.figma.com/file/XQf6F34cI0MRFJflrRc6KT/Legacy-Lessons?node-id=0%3A1">https://www.figma.com/file/XQf6F34cI0MRFJflrRc6KT/Legacy-Lessons?node-id=0%3A1</a>
  </li>

  <li>
      В шапке сайта создать элемент хлебных крошек как на картинке <a href="https://www.figma.com/file/XQf6F34cI0MRFJflrRc6KT/Legacy-Lessons?node-id=1%3A2">https://www.figma.com/file/XQf6F34cI0MRFJflrRc6KT/Legacy-Lessons?node-id=1%3A2</a>
  </li>
</ul>
  </li>
</ol>
