<h1>Разработать игру “крестики-нолики”.</h1>

<p>Необходимо дописать все пустые методы, чтобы игра полностью функционировала.</p>

<p>По клику на ячейку должен проставляться символ игрока (X или 0), который ходит в данный момент. После каждого хода нужно проверять выиграл ли кто то и закончилась ли игра. В случае выигрыша показываем Alert с информацией, кто выиграл.	Кнопка “Рестарт” должна перезаписывать начальные параметры и  перезапускать игру. </p>
