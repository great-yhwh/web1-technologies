 <p>
      Установить node-js <a href="https://nodejs.org/ru">https://nodejs.org/ru</a>
  </p>

  <p>
      Установить http-server глобально <a href="https://www.npmjs.com/package/http-server">https://www.npmjs.com/package/http-server</a>
  </p>

  <p>
      Забрать изменения из репозитория <a href="https://github.com/tgulegacy/web-technologies-2024">https://github.com/tgulegacy/web-technologies-2024</a> ветка lesson2
  </p>

  <p>Все изменения делаем в ветке lesson2</p>

  <p>Подключить другие начертания шрифта (Italic и т.д.) в файле assets/style/fonts.css по примеру из style.css</p>

  <p>Подключить файл assets/style/fonts.css в style.css</p>

  <p>Продолжить работу со страницами из 1 практики:</p>

  <p>
      Для всех параграфов присвоить класс и задать стили<br>
      font-size: 16px;<br>
      line-height: 26px;<br>
      color: #1F3F68.
  </p>

  <p>
      Для заголовка h1 создать класс и присвоить стили:<br>
      font-size: 64px;<br>
      color: #1F3F68.
  </p>

  <p>
      Для заголовка h2 (на странице контакты) создать класс и присвоить стили:<br>
      font-weight: 500;<br>
      font-size: 44px;<br>
      text-align: center.
  </p>

  <p>
      Заголовку h3 создать класс и задать стили:<br>
      font-size: 36px;<br>
      text-align: center.
  </p>

  <p>
      Заголовкам h4 создать класс и задать стили<br>
      font-size: 20px;<br>
      line-height: 30px;<br>
      color: #1F3F68.
  </p>

  <p>
      Для всех полей ввода (input, textarea) задать общий класс и к нему стили:<br>
      border: 1px solid #356EAD;<br>
      box-sizing: border-box;<br>
      border-radius: 10px;<br>
      opacity: 0.4.
  </p>

  <p>
      Кнопке отправки формы присвоить класс и к нему стиль:<br>
      background: #5A98D0;<br>
      box-shadow: 5px 20px 50px rgba(16, 112, 177, 0.2);<br>
      border-radius: 10px;<br>
      font-weight: 500.<br>
      font-size: 16px;<br>
      line-height: 26px;<br>
      text-align: center;<br>
      color: #FFFFFF;<br>
      text-transform: uppercase.
  </p>

  <p>Для формы на страницы "Контакты" добавить изображение на задний фон (изображение подберите на свой вкус)</p>

  </p>
